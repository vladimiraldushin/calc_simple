# 📊 Калькулятор юнит-экономики услуг (v1.6.1)

Интерактивный **веб-калькулятор юнит-экономики** для сервисных бизнесов и ИП.
Позволяет рассчитать рентабельность услуги или бизнеса от оборота, сравнить налоговые режимы (УСН, АУСН, патент), учесть ФОТ, комиссии и переменные расходы — и понять, при какой цене бизнес становится прибыльным.

---

## 🚀 Возможности

### 🔹 Основной функционал

* Расчёт юнит-экономики:

  * по **услуге** (единице);
  * от **оборота** (месячной выручки).
* Автоматический учёт:

  * **переменных расходов**;
  * **комиссий % от выручки**;
  * **постоянных расходов**;
  * **ФОТ** с учётом НДФЛ и страховых взносов работодателя.
* Сравнение **8 налоговых режимов**:

  * УСН 6% / 6% + НДС
  * УСН 15% (Д–Р) / 15% + НДС
  * АУСН 8% / 20% (Д–Р) / 20% + НДС
  * Патент
* Расчёт:

  * чистой прибыли и маржи;
  * точки безубыточности;
  * оптимальной цены для заданной рентабельности;
  * влияния НДС и лимитов патента.

---

## 🧮 Пример расчёта

1. Введите цену услуги или оборот.
2. Укажите расходы:

   * переменные (например, материалы, подрядчики);
   * постоянные (аренда, связь и т.п.);
   * зарплаты сотрудников (с окладом, взносами и налогами).
3. Выберите налоговый режим.
4. Калькулятор покажет:

   * чистую прибыль;
   * налоги;
   * точку безубыточности;
   * рекомендуемую цену для целевой маржи.

---

## 🧠 Логика расчётов

Ключевой JS-модуль: [`unit-economy-app.js`](./unit-economy-app.js)

Рассчитываются:

* **Маржа / вклад** на 1 услугу:
  `Маржа = Цена (без НДС) − Переменные расходы − Комиссии`
* **Прибыль до налога режима**
  `Валовой доход − Постоянные расходы − ФОТ`
* **Налог режима** — по выбранной системе:

  * УСН 6% (с вычетом страховых);
  * УСН 15% (с минимальным налогом);
  * АУСН 8% / 20%;
  * Патент (годовой /12);
  * учёт НДС при превышении лимита.
* **Чистая прибыль**
  `Прибыль до налога − Налоги − НДС`
* **Точка безубыточности**
  `Постоянные / (Маржа на услугу)`

## 💻 Установка и запуск

### Вариант 1: Открыть локально

1. Скачайте репозиторий (`Code → Download ZIP`)
2. Распакуйте архив
3. Откройте файл `index.html` в браузере

1. Зайдите в настройки репозитория → **Pages**

3. Через несколько минут приложение будет доступно по адресу:

## 📱 Адаптивность

Интерфейс оптимизирован под мобильные устройства:

* карточки в одну колонку;
* поля и таблицы адаптируются по ширине;
* KPI-плитки перестраиваются в 1–2 ряда.

Файл [`Styles.mobile.css`](./Styles.mobile.css) подключается **после** `styles.css` и переопределяет ключевые правила.
