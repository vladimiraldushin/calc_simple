# UnitEconomy — модульный калькулятор юнит-экономики

## Как запустить

1. Откройте `index.html` в современном браузере (Chrome 109+, Safari 15+, Edge 109+).
2. Все зависимости являются нативными ES-модулями, сборка не требуется.

## Структура

- `assets/css` — базовые токены, сетка и компоненты.
- `assets/js/config` — конфигурация приложения и пресеты налоговых режимов.
- `assets/js/core` — состояние, шина событий, движки расчётов.
- `assets/js/modules` — независимые модули (юнит-экономика, сценарии цены, настройки налогов).

## Возможности

- Постатейный учёт переменных и постоянных расходов.
- Поддержка УСН, АУСН, ПСН, ОСНО и НДС.
- Автоматический пересчёт ключевых метрик.
- Сценарный анализ цены с шагами в % и ₽.
- Обновление пресетов налоговых режимов из конфигурации.
